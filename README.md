# 2026학년도 제1회 SEED Conference 제출 시스템

부산과학고등학교 지능정보교육부 SEED Conference의 팀 신청, 산출물 제출, 지도교사 회신, 현황판을 한곳에서 운영하는 웹페이지입니다.

| 페이지 | 대상 | 하는 일 |
|---|---|---|
| `index.html` | 모두 | 처음 화면, 일정 |
| `student.html` | 학생(팀장) | 팀 신청 → 팀 코드 발급 (1인 1회) |
| `submit.html` | 학생(팀장) | 팀장 학번 + 팀 코드로 단계별 파일 제출 (단계별 1회) |
| `board.html` | 모두 | 참가 현황판(숫자만, 이름 없음) |
| `teacher.html` | 지도교사(교사용 비밀번호) | 학생 명단·제출 파일 확인, 지도 수락 회신(1인 1회) |
| `admin.html` | 담당자(관리자 비밀번호) | 전체 현황, 엑셀 내려받기, 신청·파일·회신 삭제 |

- 화면: GitHub Pages(정적 파일)
- 저장: 구글 시트 + 구글 드라이브(공유하지 않는 폴더), 서버 코드는 `apps-script/Code.gs`
- 설치 방법: [SETUP.md](SETUP.md), 보안 설계: [SECURITY.md](SECURITY.md)
- 이 저장소에는 비밀번호나 학생 정보가 들어 있지 않습니다.
