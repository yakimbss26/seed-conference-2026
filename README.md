# 2026학년도 제1회 SEED Conference 제출 페이지

부산과학고등학교 지능정보교육부 SEED Conference의 학생 팀 신청서와 지도교사 수락 회신서를 작성하는 정적 웹페이지입니다.

- 처음 화면: `index.html`
- 학생 팀 신청서: `student.html`
- 지도교사 수락 회신서: `teacher.html`
- 담당자 취합 페이지: `collect.html` (처음 화면에는 링크하지 않음)

## 동작 방식

- 서버, 데이터베이스, 외부 전송이 없습니다. 입력한 내용은 브라우저 안에서 엑셀 파일로 만들어 내려받기만 합니다.
- 제출은 내려받은 엑셀 파일을 담당자에게 팀즈로 보내는 방식입니다.
- 이 저장소에는 학생·교사 개인정보를 올리지 않습니다.

자세한 보안 설계는 [SECURITY.md](SECURITY.md)를 참고하세요.
